# 2026-07-31 skill_tag 誤標修正

接續 2026-07-29 題庫稽核留下的第一順位選項：`skill_tag` 誤標約 15–18 題。

---

## 做了什麼

### 判準

`word_form`（詞性判斷）只有在**四個選項詞性不同**時才名副其實——因為那時是空格的文法在決定答案
（`speak / spoken / speaker / speaking`，句子要名詞，所以選 speaker）。

四個選項**詞性相同**時，文法一個都排除不掉，決定答案的是字義：

```
p5-xd-0206  obviously / financially / fiercely / automatically   ← 四個都是副詞
解析：「空格修飾動詞 notifies，需副詞。」                          ← 這句話排除不了任何一個
```

這正是誤標的指紋：**生成的解析宣告了一條 POS 規則，而四個選項全部滿足它**。

誤標會實際傷到使用者：`skill_tag` 是 `getWeakestSkills` 的輸入，
所以一個字彙缺口會被判成詞性弱點，然後系統叫你去練詞性判斷——練錯東西。

### 找法

先用 stemmer，失敗（把 significance/significantly 拆開、把 find/finance/fine 併在一起）。
改用**四個選項的共同字首長度**，分布是乾淨的雙峰：

```
word_form (255 題單字選項)
  lcp=0  ###### 21     ← 不同字，候選
  lcp=1-3        9     ← 稀疏地帶
  lcp≥4        225     ← 真的同一字族（signif- / resilien- / efficien-）
```

lcp<4 的 30 題逐題判讀 + 讀解析，結論：

| | 題數 | 例 |
|---|---|---|
| 真誤標 → `business_vocabulary` | **15** | `p5-xd-0065` indifferently/presumably/completely/unbearably |
| 詞性確實有在做事，保留 `word_form` | 14 | `p5-xd-0280` accomplishing/**mindful**/**successful**/climbing（POS 排除掉兩個） |
| 反向誤標 → `word_form` | **1** | `p5-ext-147` compete/competition/competitive/competitor |

保留的判例值得記：`p5-xd-0119` `no/not/none/any` 與 `p5-xd-0194` `every/other/most/several`
**沒有動**。前者詞性不同（限定詞／副詞／代名詞），後者是量詞單複數一致性——都是文法題，
搬到 vocabulary 只會更錯。分類法沒有「限定詞」這一類，這是已知限制，不是可以硬塞的理由。

## 沒做什麼

**1. 那 15 題的解析沒有改寫。** 它們開頭的「需用副詞」現在看起來像廢話（確實是），
但那句話**並不假**，而且每則解析後面都有給真正的理由
（「automatically 符合句意；obviously、financially、fiercely 語意不符」）。
改寫 15 則解析是你沒要求的內容生成，而現有文字不會誤導答案本身。

**2. gate 只抓得到 13/15。** 另 2 題（`valuable/impressive/eligible/flexible`、
`basic/compelling/necessary/natural`）四個都是形容詞但沒有共同字尾可測，只能靠讀。
把規則放寬到「用詞典查詞性」會引入誤報，不划算——現行規則的價值在於它零誤報。

**3. 只掃了 Part 5/6 的 `word_form` 與 `business_vocabulary`。**
其他標籤（tense、preposition…）沒有對應的形狀特徵可自動檢查，未查。
